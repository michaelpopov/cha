1. About CHA

CHA is a private application for conversations with one or more AI characters. It lets you choose who you speak as, choose who answers, organize conversations into forums, and keep useful sessions.

On a compatible Mac, CHA installs in the Applications folder and opens in its own window like any other application. Chrome, Safari, and other web browsers are not needed. CHA keeps its settings and conversations on the Mac and contacts the selected AI provider when a character prepares a reply.

CHA is intended for personal use. It does not replace professional medical, legal, financial, or emergency advice.

2. Install and start CHA on macOS

The standalone edition of CHA is a normal Mac application. Installation requires no Terminal commands and everyday use requires no web browser.

Before you begin

You need:

  • A Mac with Apple silicon, such as an M1, M2, M3, M4, or later chip. This edition does not run on an Intel Mac.
  • A copy of CHA built for the macOS version on that Mac. A build made for a newer macOS release cannot run on an older release.
  • An internet connection for AI-generated replies.
  • An OpenAI Platform API key. If you do not have one, sign in to the OpenAI API key page and create a key. Treat the key like a password: do not share it or include it in messages or downloaded conversations.

Install the application

  1. Obtain CHA-macos-<version>.zip or CHA.app from a source you trust.
  2. If you received a ZIP file, double-click it in Finder. Finder extracts CHA.app and a cha.toml configuration example.
  3. Open a second Finder window and select Applications.
  4. Drag CHA.app into the Applications folder.
  5. Open Applications and double-click CHA. Do not open the application from inside the ZIP file and do not move or edit files inside CHA.app.

If macOS blocks the first launch

Because this personal-use application does not come from the Mac App Store, macOS may say that Apple cannot check it or that its developer cannot be verified. Continue only if you trust the person or place from which you received this exact copy.

  1. Try to open CHA once, then dismiss the macOS warning.
  2. Choose Apple menu > System Settings, then select Privacy & Security in the sidebar.
  3. Scroll to the Security area and select Open Anyway beside the message about CHA.
  4. Enter the Mac login password if asked, confirm the choice, and select Open in the final warning.

Do not override a warning that says CHA will damage the Mac, and do not continue if the copy came from an unexpected or untrusted source. Obtain a fresh copy instead. For more context, see Apple's guidance for opening applications safely.

Complete the first launch

  1. Wait for the Set up CHA window to appear.
  2. Paste the OpenAI API key into the protected field.
  3. Select Continue.
  4. Wait while CHA prepares itself. The main window opens at the Welcome session when setup is complete.

CHA remembers the key, settings, and saved conversations on that Mac. You do not need to repeat setup each time the application opens.

The Welcome session is temporary. It is useful for a quick conversation, but it disappears when CHA quits. Create a normal session in a forum when you want the conversation to be saved.

Send your first message

  1. Click the message box at the bottom of the chat.
  2. Type your message.
  3. Press Ctrl+Enter, or select the Send button.

Pressing Enter by itself adds a new line. This makes it easy to write a message with several paragraphs before sending it.

Make the message box larger

Drag the divider above the message box upward or downward. The box can use up to 80% of the chat height. When the divider has keyboard focus, use the Up and Down arrow keys to resize it. Press Home or double-click the divider to return to the automatic size.

Open and quit CHA

  • To open CHA later, double-click it in Applications. You can also drag CHA from Applications to the Dock for convenient access.
  • To quit, choose CHA > Quit CHA, press Command+Q, or close CHA's only window.

Change the OpenAI API key

  1. Choose CHA > Change API Key….
  2. Paste the replacement key and select Continue.
  3. Select OK after CHA confirms that the key was saved.
  4. Quit CHA and open it again. The new key is used after the restart.

Install an updated version

  1. Quit CHA completely.
  2. Extract the new CHA.app if it arrived in a ZIP file.
  3. Drag the new copy into Applications.
  4. Select Replace when Finder asks what to do.
  5. Open CHA normally. Existing settings and saved conversations remain.

Copy CHA to another Mac

Copy the ZIP file or CHA.app to the other Mac, place CHA in that Mac's Applications folder, and follow the first-launch steps above. The application can be copied, but the OpenAI API key and saved conversations do not travel with it. The other Mac starts with its own setup and its own conversations.

3. The four main ideas

How CHA organizes a conversation
Item What it means Example
Persona The identity and background you use when speaking. You, a guest, or a role created for a particular kind of discussion.
Character The AI counterpart that replies, together with its instructions and provider settings. A general assistant, tutor, editor, or historical voice.
Forum A group of characters and the default persona used with them. A study group or a collection of advisers.
Session One saved conversation inside a forum. “Planning the autumn trip.”

A forum provides the setting. A persona says who is asking. A character says who answers. A session contains the actual conversation.

4. Finding your way around

The sidebar contains four main areas:

  • Personas shows the available speaking identities and their descriptions. Opening a persona here does not change your current persona.
  • Characters shows the available AI characters. Select one to read its description or, when allowed, change its settings.
  • Forums shows groups of characters. Open a forum to see its members, active persona, and saved sessions.
  • Recent gives quick access to recently used sessions.

On a small screen, open the sidebar when you need it and close it to give the conversation more room.

5. Creating and managing sessions

Create a saved session

  1. Open Forums in the sidebar.
  2. Select the forum you want to use.
  3. Select New session.
  4. Enter a title when requested, then begin the conversation.

Open an earlier session

Select a session under Recent, or open its forum and choose it from the session list. Sessions in a forum are shown with the most recently used items first.

Rename, download, or delete

Open the action menu beside a session in the Recent list. Choose:

  • Rename to change the displayed title.
  • Download to save a Markdown copy.
  • Delete to remove the session from CHA.

A deleted session can no longer be opened in CHA. Download it first if you may need a readable copy later.

6. Having a conversation

See who is speaking

The information above the message box shows the forum, the persona in the From position, and the character in the To position. Check this line before sending if the forum has several members.

Choose one character for a message

Start a message with @Name to address a particular character: 

@Seneca How should I think about this setback?

CHA accepts an unambiguous full name, identifier, or partial name without regard to letter case. To start ordinary text with a literal at sign, type two at signs: @@example becomes @example.

Ask several characters

Use /mcast to send one prompt to several forum members: 

/mcast @Seneca @Epictetus What matters most here?

CHA shows the question once. A horizontal line separates each reply, so it remains clear where one answer ends and the next begins.

Record a message without an AI reply

Start a message with @- to add it to the conversation without asking a character to respond: 

@- I made the decision this morning.

The note is saved in the conversation history. A character selected later can use it as context. Use /@- to stay in recording mode until you choose a character again.

Stop a reply

While CHA is generating an answer, the Send button changes to Stop. Select it to stop generation. You can also use the /stop command.

Write in any language

Enter text directly in the language you want to use. For a different alphabet or keyboard layout, use the normal input settings provided by your computer or phone.

7. Chat commands

Commands begin with a slash and are entered in the same box as an ordinary message. The following commands are available during a session.

Session commands
Command Purpose Example or note
/clear Clear the current transcript and begin with an empty conversation. Use with care if you still need the earlier exchange.
/cover Keep earlier messages visible, but leave them out of later AI requests. Useful when the conversation has changed subject.
/uncover Return covered messages to the context used for future replies.  
/mcast Send one prompt to more than one character. /mcast @One @Two Your question
/info Show information about the current session.  
/characters List the characters in the current forum. /agents is an older name for the same command.
/@Name Choose the default character and save that choice for the forum. /@Seneca
/@- Enter recording mode, in which messages are saved without AI replies. This choice applies only to the current session.
/!Name Choose your persona and save that choice for the forum. /!Michael
/style name Change the conversation's visual text style for this session. Use /style to see the current style and /style default to restore it.
/stop Stop the reply that is being generated.  
/exit Close the live session. You can open a saved session again later.

8. Character settings

Open Characters, select a character, and then open Settings. The Settings option appears only for characters that can be changed. The built-in Assistant does not have this screen.

Character settings
Setting Meaning
Provider The AI provider and model used by this character.
Reasoning effort How much internal work the model may do before answering. Higher settings can take longer and may cost more.
Web search Whether the character may search the web, must search it, or must not search it.
Style The font treatment used to display this character's messages.

Saving character settings applies them to open conversations. If a reply is being generated, that unfinished reply will be lost.

9. Backing up and editing CHA data

The Database menu can export or import workspace configuration and can upload or download the complete database. These operations run inside the current CHA process; the application does not restart or launch a separate console program.

Find the active configuration files

The cha.toml extracted from the ZIP is an example. The application uses its active files here: 

~/Library/Application Support/CHA/cha.toml
~/Library/Application Support/CHA/.env

In Finder, choose Go > Go to Folder…, enter ~/Library/Application Support/CHA, and select Go. Quit and reopen CHA after changing either active file so the new settings and menu availability take effect.

Export, edit, and import workspace configuration

The optional modify setting in the active cha.toml names the directory used by both operations. A relative path starts from the directory containing cha.toml: 

modify = "modify"

When this setting is absent, Import and Export are disabled. To edit workspace configuration:

  1. Wait for any current AI reply to finish.
  2. Choose Database > Export. CHA deletes an existing directory at the configured modify path, recreates it, and writes the current workspace configuration there.
  3. Edit the exported .toml or .md files.
  4. Choose Database > Import… and confirm the change.
  5. Wait for CHA to validate, store, and display the imported workspace.

Export permanently replaces the existing modify directory. Copy out any edits you still need before exporting again. Import replaces the complete workspace configuration and can remove sessions belonging to forums that are no longer configured.

Upload or download the complete database

Upload and Download use Cloudflare R2 through its S3-compatible API. They are enabled only when all three of these entries have nonempty values in the active .env file or the environment that launched CHA: 

CHA_R2_URL=https://example.r2.cloudflarestorage.com/bucket
CHA_R2_ACCESS_KEY_ID=your-access-key-id
CHA_R2_SECRET_ACCESS_KEY=your-secret-access-key
  • Database > Upload validates and uploads the current database, replacing the object with the same database filename.
  • Database > Download… asks for confirmation, saves the current database beside itself with a .bac suffix, downloads and validates the R2 copy, and refreshes CHA.

All four Database menu items are temporarily disabled while one database operation is running.

10. Downloading conversations

Use Download in a session's action menu to save a Markdown file. Markdown is plain text that remains readable in an ordinary text editor and is also supported by many note-taking applications.

The exported file is designed to be compact:

  • The session start time appears once near the beginning.
  • Each speaker is shown as a monospace badge followed by a middle dot.
  • Paragraphs within one reply stay close together.
  • A small gap separates one message from the next.
<!-- CHA session: An evening conversation -->
*Started September 03, 2026 at 17:47 PDT*

`Michael` · How can I make better use of the rest of today?

`Montaigne` · Begin by deciding whether you need rest or attention.  
Then choose one small act and do it completely.

11. Privacy and data

  • In the standalone Mac application, saved conversations and settings remain on that Mac. Replacing the application preserves them, while copying only the application to another Mac does not transfer them.
  • Prompts and the needed conversation history are sent to the configured AI provider when you request a reply.
  • If web search is enabled, the provider may use the web to prepare an answer. CHA stores the final answer, not the provider's search details.
  • Downloaded conversation files are separate copies. Protect or delete those files yourself when you no longer need them.
  • If you use Database Upload, the complete database is copied to the configured R2 bucket and protected by that account's access controls.
  • Your API key is stored on the Mac and should be treated like a password.

Anyone with access to your Mac account or downloaded conversation files may be able to read your conversations. Lock your Mac and do not share your API key.

12. Troubleshooting

Common problems
Problem What to try
macOS says Apple cannot check CHA or cannot verify its developer. If the copy came from a trusted source, follow If macOS blocks the first launch. Otherwise, obtain a fresh copy from someone you trust.
CHA says that it could not open. Quit CHA, wait a few seconds, and open it again from Applications. If the problem remains, restart the Mac.
CHA says that this copy is incomplete. Delete only the application, obtain a fresh ZIP file, extract it again, and move the new CHA.app into Applications. Saved conversations remain on the Mac.
A reply fails immediately. Check the internet connection. Choose CHA > Change API Key…, save a valid key, quit CHA, and open it again.
A reply stops during generation. Check the internet connection, wait briefly, and send the message again. If the AI provider is unavailable, try again later.
The wrong character answers. Check the To value above the message box. Use /@Name to choose a default or begin one message with @Name.
The wrong persona is shown. Check the From value and use /!Name to choose another persona.
Typing Enter sends nothing. This is expected. Enter adds a new line; use Ctrl+Enter or the Send button.
Import and Export are disabled. Add a nonempty modify path to the active cha.toml, then quit and reopen CHA.
Upload and Download are disabled. Set all three CHA_R2_URL, CHA_R2_ACCESS_KEY_ID, and CHA_R2_SECRET_ACCESS_KEY values, then quit and reopen CHA.
