CHA User Manual

This manual describes the daily use of CHA: conversations, notes, voice, the Library, and the ChaWeb browser client.

It does not describe installation or setup. The Settings screens, providers, API keys, voices, vaults, synchronization, and the creation of forums, characters and personas are subjects of the administrator guide. Where a function needs setup, this manual says so in a line that starts with Setup:.

Part 1 — Guide

1. About CHA

CHA is a desktop application for conversations with AI characters. It runs on macOS and Windows.

With CHA you can:

  • Talk to one character, or to several characters in the same conversation.
  • Dictate your messages and listen to the answers.
  • Keep notes, import books, web pages and text files, and mark them up.
  • Give a character a note, a text file, or a searchable Library to work with.

ChaWeb is a second client. It runs in a web browser, for example on a phone, and it uses the same data. ChaWeb has fewer functions than the desktop application. See ChaWeb.

2. Concepts

Vault. A vault is one complete set of data: forums, characters, personas, sessions and notes. One vault is active at a time. When you change the vault, all lists in the window change.

Forum. A forum is a group of characters. Each forum has its own sessions and its own folder in Notes. In a forum you always speak as one persona.

Character. A character is an AI participant. It has a name, a description and a profile. It can also have a voice, a text style and pictures.

Persona. A persona is the identity that you speak as. The chat screen shows it after From:.

Session. A session is one conversation in one forum. CHA stores it in the vault.

Entrance and Welcome. Each vault has the built-in forum Entrance. It contains one session, Welcome. CHA starts in Welcome. There you speak as Guest with the character Assistant. CHA does not keep the Welcome conversation after you close the application. You cannot create other sessions in Entrance.

Assistant. Assistant is a built-in character. In the Welcome session it can examine and change the CHA configuration when you ask it to. The administrator guide describes this function.

Notes. Notes are documents in a folder tree. Each vault has its own notes.

Library. A Library is a set of cloud stores that are selected for one forum. A cloud store holds a copy of your notes at a provider, in a form that characters can search.

The window has a sidebar on the left and a main panel on the right.

Sidebar

At the top of the sidebar there are two tabs:

  • Chat shows the forums and the recent sessions.
  • Notes shows the notes tree.

A tab changes only the sidebar. The main panel changes when you open a session or a note.

The Chat tab has two lists:

  • Forums shows all forums of the vault, Entrance included. Click a forum to see its sessions.
  • Recent Sessions shows the used sessions of all forums. The session with the newest change is first. Each row shows the session name and the forum name. Click a row to open the session.

A dot on a session row shows activity: a character is generating an answer in that session, or the session has a new answer that you did not see.

At the bottom of the sidebar there is the Vault list and the Settings button.

Menus

A forum row and a session row have a menu button at the right. A right-click on the row opens the same menu. The Entrance forum and the Welcome session have no menu.

In an open menu, use the Up and Down arrow keys, Home and End to move, and Escape to close the menu.

Main panel

The main panel shows the chat or a note. With View → Split view, it shows the note on the left and the chat on the right.

The window title shows the vault name and the name of the open session or note.

Parts that you can resize

Part With the mouse With the keyboard
Sidebar width Drag the divider. Left and Right arrow keys on the divider.
Forums and Recent Sessions Drag the divider between the lists. Up and Down arrow keys, Home, End.
Notes and chat in split view Drag the divider. Left and Right arrow keys.
Message editor Drag the bar above it. Double-click to reset. Up and Down arrow keys, Home to reset.
Picture panel Drag the divider. Left and Right arrow keys.

Show and hide parts

The View menu shows and hides the sidebar, the toolbars, the picture panel and other parts. See View menu. CHA keeps these selections for the next start.

Change the vault

  1. Click the Vault list at the bottom of the sidebar.
  2. Select a vault.
  3. If the vault has a password, the dialog Open vault name shows. Type the password and click Open vault.

CHA saves the open note, changes the vault, and shows the Welcome conversation. The text that you typed in a prompt but did not send is removed.

Setup: The administrator guide describes how to create and manage vaults.

A second window

On macOS, Window → New Instance (Cmd+N) starts one more CHA window.

Events

Some tasks continue in the background: note compression, note audio, session summaries, and uploads to a store. CHA records their results as events.

To see the events:

  1. Click Settings at the bottom of the sidebar.
  2. Click Events.

Each event has a type (information, success, warning or error), a date and time, and a message. CHA keeps the newest 1000 events.

4. First steps

Setup: Before the first conversation, the vault must have a forum with a minimum of one character, and that character must have a provider. See the administrator guide.

  1. Start CHA. The Welcome conversation shows.
  2. On the Chat tab, click a forum in the Forums list. The Sessions screen shows.
  3. Click New session. An empty chat opens.
  4. Type a message and press Enter.
  5. Read the answer.

After the first message, CHA gives the session a name and adds it to Recent Sessions.

The Sessions screen

To open the Sessions screen, click a forum in the Forums list.

The screen shows:

  • All forums — goes to the list of forums.
  • A row with the forum name and the names of its members.
  • New session. The Entrance forum does not have this row.
  • The sessions of the forum. The session with the newest change is first. Each row shows the name and the age, for example Now, 5m, 3h, 2d, or a date.

CHA has no search function for sessions.

Create a session

Use one of these methods:

  • On the Sessions screen, click New session.
  • In the sidebar, open the menu of a forum and click Create new session.

The chat opens immediately.

Session names

A new session has the name New session. After your first message, CHA makes a short name of a maximum of six words, in the language of your message. If CHA cannot make a name, it uses the date and time as the name.

When you rename a session yourself, CHA does not change the name again.

Sessions that you do not use

If you create a session and go away from it before you send a message or add a file, CHA deletes that session.

Open a session

Click the session in Recent Sessions or on the Sessions screen.

If the session cannot open, the screen shows Session unavailable with the buttons Retry and Browse sessions.

The session menu

The menu is available for the rows in Recent Sessions. It has these commands:

Command Result
Download Saves the conversation as a Markdown file. The suggested file name is the session name.
Save summary Writes a summary of the conversation into Notes. See Session summaries.
Clear audio cache Removes the stored audio of the answers in this session.
Rename… Opens the dialog Rename session. Type the name and click Rename.
Delete… Opens the dialog Delete session?. Click Delete. You cannot open a deleted session again.

The chat screen

From top to bottom, the chat screen has:

  • The chat toolbar, with the lists Character, Model and Effort, and the Playback speed control.
  • The conversation.
  • The prompt area: the message editor, the target list, the microphone button and the send button.
  • A status row. It shows the forum, From: your persona, and To: the target.

Send a message

  1. Type the message in the editor.
  2. Press Enter, or click Send message.

To start a new line in the message, press Ctrl+Enter. On macOS this is the Control key. Shift+Enter does not start a new line. It sends the message.

After you send, the conversation moves so that your new message is at the top. If you scroll up while an answer arrives, the view stays where you put it. Scroll to the end to follow the answer again.

While a character generates an answer, you can type the next message but you cannot send it.

Stop an answer

Click Stop generation. This button replaces the send button while an answer is in work.

The part of the answer that is already there stays in the conversation with the status Stopped. If the message went to several characters, the remaining characters do not answer.

Select who gets your messages

The target is the receiver of your messages. The status row shows it after To:.

To change the target, use the list Choose message target in the prompt area:

  • A character name — that character answers.
  • All characters — each character of the forum answers, one after the other.
  • Self-notes — CHA saves your messages in the conversation and no character answers. The characters see these messages later as part of the conversation.

The Character list in the chat toolbar also changes the target.

CHA keeps the last character that you select as the start target for new sessions in that forum.

Address one message to one character

Start the message with @ and the name of a character:

@Anna what do you think?

That character answers this one message. The target does not change.

You can type the full name, one word of the name, or the start of the name. Capital letters are not important. If the text agrees with more than one character, CHA asks you to type more of the name.

To write a note to yourself in the middle of a conversation, use @-:

@- check this number tomorrow

To start a normal message with the character @, type @@.

Send one message to several characters

Use the command /mcast:

/mcast What is your opinion?
/mcast @Anna, @Boris What is your opinion?

Without names, all characters of the forum answer. With names, only those characters answer. All of them get the same conversation history, so no character sees the answer of another character to this message before it answers.

The conversation shows your message one time, with the answers below it.

Automatic recipient detection

Setup: This function works only when recipient detection is configured.

When you send a message without @ and without a command, CHA reads the message and looks for the name or the nickname of a character.

Your message Result
Addresses one character by name or nickname The message goes to that character. The target changes to that character.
Addresses the whole forum The message goes to all characters. The target changes to All characters.
Is clearly a note to yourself CHA saves it as a self-note. The target changes to Self-notes.
Has no clear receiver The message goes to the current target.

If the detection fails, CHA uses the current target and tells you in the conversation.

Model and effort

The chat toolbar shows the settings of one character: the character that generates an answer, or the target, or the last speaker.

  • Model selects the provider for this character. Default uses the provider of the character. The list is disabled when the forum has a default provider.
  • Effort selects the reasoning effort: Default, None, Low, Medium, High or Extra high.

The selections apply to that character in this session only.

Information and controls on a message

Below each message there is a row with information and buttons.

Item Function
Time The time of the message. Point at it to see the full date.
Token count The size of the request and the answer. Point at it to see the input and output tokens.
Globe The request included data from the web.
Copy to clipboard Copies the text of the message.
Speaker Plays the answer. See Voice.
Cover Hides the conversation up to this answer from the characters. See below.
Trash Deletes the answer and your message that caused it.

An answer that failed shows as an entry with the name Error and the status Failed. You can delete it with the trash button.

Delete an answer

  1. Click the trash button below the answer.
  2. In the dialog Delete response?, click Delete response.

CHA deletes the answer and the message that caused it. You cannot undo this.

Cover the start of a conversation

In a long conversation you can keep the early part on the screen but not send it to the characters.

  1. Find the last answer of the part that you want to cover.
  2. Click the cover button below that answer.

The covered part moves into a box. The characters do not get it with later messages. To move the limit, click the cover button on a different answer. To remove the cover, click Uncover transcript on the last covered message.

CHA does not store the cover with the session. After a restart of CHA, the characters get the full conversation again.

Delete the full conversation

Send the command /clear.

CHA deletes all messages of the session immediately. It does not ask for confirmation, and you cannot undo this.

Progress of an answer

While an answer is in work, a line shows what the character does: it prepares the answer, writes it, searches the web, or reads pages. When the character uses the web, you can open the line to see the search texts and the sites.

How answers show

Answers show with headings, lists, tables and code blocks. Web links in an answer show as plain text. You cannot click them.

If the connection to a session stops

A bar above the prompt area shows the state, for example Reconnecting live updates…. If CHA cannot restore the connection, use the buttons Retry, Browse sessions or Return to start. Your conversation is saved.

7. Material in a chat

In this chapter
  • Add a text file
  • Add a note

You can give the characters a text file or a note. CHA keeps a copy in the session and sends the text with each later message.

Add a text file

Use one of these methods:

  • Drag one file from the file manager onto the message editor.
  • Send a message that contains only the full path of the file.

The conversation shows the message Added file “name” to this chat.

The file must be UTF-8 text of a maximum of 256 KiB.

To replace the copy with a newer version of the file, add the file again.

Add a note

  1. Click the Notes tab.
  2. Open the menu of the note and click Copy Ref ID. The Ref ID is ## and six characters.
  3. Go to the chat. Paste the Ref ID as the only text of a message and send it.

The conversation shows the message Added note “name” to this chat.

Important points:

  • The chat has its own copy. Later changes in the note do not change the copy. To refresh the copy, send the Ref ID again.
  • If the note has a compressed version, the chat uses the compressed text. See Compress a note.
  • The limit is 256 KiB of text.

With View → Split view you can read the note and use the chat at the same time.

8. What characters can use

In this chapter
  • Summaries of earlier sessions
  • The web
  • The Library

The characters decide when to use these sources. You do not start them with a command. Ask your question in normal words.

Summaries and the Library are not available in the Welcome session.

Summaries of earlier sessions

A character can search and read the saved summaries of other sessions in the same forum. It cannot read the original messages of other sessions.

A session has a summary only after you use Save summary. See Session summaries.

The web

Setup: Web search and page reading must be configured and enabled for the character.

A character can search the web and read pages. The progress line shows this work. After the answer, the globe icon shows that the request included data from the web.

The Library

Setup: An administrator selects the cloud stores of a forum Library.

All characters of a forum can search the Library of that forum. See Library.

Dictate a message

Setup: The microphone button shows only when voice input is configured.

  1. Click Start voice input.
  2. Speak. The text shows in the message editor.
  3. Click Stop voice input, or send the message.

Dictation is in English. It is in Russian while the A→Я button is on.

Only one prompt can use the microphone at a time: the chat prompt or the notes prompt.

Send by voice

Say the send phrase at the end of your message. The default phrase is “over to you”.

CHA removes the phrase, waits one second, and sends the message. The microphone stays on, so you can continue to speak after the answer.

Spoken punctuation

Say (English) Say (Russian) Result
comma запятая ,
period, full stop точка .
question mark вопросительный знак, знак вопроса ?
exclamation mark, exclamation point восклицательный знак, знак восклицания !
new line новая строка, с новой строки A new line

Listen to an answer

Setup: The speaker buttons show only when voice output is configured.

  1. Click the speaker button below an answer. CHA generates the audio and plays it. The next time, the audio starts without delay because CHA stores it.
  2. To stop, click the button again. The next play continues from the position where you stopped.

To pause and continue, click the text of the conversation, or press Space when the conversation has the focus.

CHA plays one audio at a time, in chat and in notes.

Automatic audio for new answers

Click Auto audio response in the status row.

  • Each new answer plays automatically, in the order of the conversation.
  • The microphone starts, if it is not already on.

Click the button again to stop the automatic audio and the microphone. The function also goes off when you open a different session or change the vault.

Playback speed

Use − and + in the Playback speed control of the chat toolbar. The range is 0.5× to 2.0×. The speed stays the same when you open a different session.

Stored audio

CHA stores the audio of each answer in the session. To remove it, use Clear audio cache in the session menu. If the stored audio is gone, click the speaker button to generate it again.

Microphone during playback

While audio plays, CHA mutes the microphone and ignores what it hears. This prevents the voice of a character from going into your message.

Type Russian with a Latin keyboard

  1. Select View → Russian. The A→Я button shows in the prompt areas.
  2. Click A→Я, or press Ctrl+Shift+Y.

While the button is on, CHA changes the Latin letters that you type into Russian letters. Text that you paste does not change.

The character + keeps two letters apart.

The Notes screen

Click the Notes tab to see the tree. Click a note in the tree to open it.

From top to bottom, the Notes screen has:

  • The toolbar.
  • The note.
  • The prompt.

View → Toolbar and View → Notes prompt show and hide the toolbar and the prompt.

The tree

The first row of the tree is the vault. Below it are folders and notes. In each folder the order is: folders, then notes in alphabetical order, then the item ANNOTATIONS.

Each row has a menu button, ⋯. A small dot on a note shows that the note has a compressed version. A read-only note that has audio has a tinted background.

Keyboard: use the arrow keys, Home and End to move in the tree. Press Enter to open a note or a folder. Press Shift+F10 to open the menu of a row.

The tree has no command to move an item to a different folder.

Kinds of items

Item What it is What you can do
Folder Holds notes and folders. All folder commands.
Note A document. All note commands.
Forums folder CHA makes it. It has one folder for each forum, with the name of the forum. Export folder… only. You cannot create, rename or delete items here. When a forum is deleted, its folder and the notes in it are deleted too.
Summary note The summary of a session, in the folder of its forum. The note commands, but not Rename, Compress and Show compressed.
ANNOTATIONS CHA makes it. It lists the highlights and comments of the notes in one folder. Open it and use Copy Ref ID. You cannot change it.

Create a note or a folder

  1. Open the menu of a folder, or of the vault row.
  2. Click New note or New folder.
  3. Type a name and click Create.

A new note opens immediately.

In the field for a new note you can also type a web address or the full path of a text file. CHA then creates the note and imports the page or the file into it.

Rules for names: a maximum of 200 characters, no space at the start or the end, and no two items with the same name in one folder. The name ANNOTATIONS is reserved.

Rename and delete

Open the menu of the item and click Rename or Delete.

CHA asks for confirmation before it deletes. It does not ask when the folder is empty or the note has almost no text. When you delete a folder, CHA deletes all notes and folders in it. You cannot undo a deletion.

Write and format

Type in the note. The toolbar has these controls:

Button Commands
Content Upload (import a text file), Copy All
History Undo, Redo
Edit Bold, Italic, Underline
Highlight Marks or unmarks the selected text.
Font size Increase font size, Decrease font size
Playback speed Decrease speed, Increase speed, Default speed
Headings Title, Chapter, Section
Insert List (Bullet list, Numbered list), Picture, Code
Find Opens the find bar.
Jump to heading Shows the headings of the note. Click one to go there.
Highlights Shows the highlights and comments of the note. Click one to go there.

A right-click in the note opens a menu with Cut, Copy, Copy JSON, Paste, Bold, Italic, Highlight and Add comment.

More points:

  • A web address that you type or paste becomes a link. A click on a link opens it in the web browser.
  • To add a picture, use Insert → Picture, or paste an image. The formats are PNG, JPEG, WebP and GIF.
  • When you paste formatted text, CHA keeps the basic formatting and removes the rest. A table becomes lines of text.

The notes prompt

The prompt below the note is a second way to add text. Type in the prompt and press Enter. The text becomes a new paragraph at the cursor position. Ctrl+Enter starts a new line in the prompt.

You can dictate into this prompt as you do in a chat.

The prompt does not send text to a character. It also has these special functions:

  • A web address imports that page. See Import a web page.
  • The full path of a text file imports that file. See Import a text file.
  • Text in the prompt becomes a comment. See Comments.

Saving

CHA saves a note automatically, five seconds after a change. It also saves when you open a different note, go to a different screen, or close the window. There is no save command.

If a save fails when you go away from a note, a dialog gives you three choices: Retry, Stay in the note, or Discard the changes.

CHA remembers the scroll position of each note.

Read-only notes

A read-only note is safe from accidental changes. To change the state, open the menu of the note and click Make read-only or Make editable.

In a read-only note:

  • You cannot change the text, and you cannot add text with the prompt.
  • You can add and remove highlights and comments.
  • You can generate and play audio.

CHA makes a note read-only when you import a file or a book into it, or a web page into an empty note.

Find and replace

Click Find in the toolbar, or press Cmd+F (macOS) or Ctrl+F (Windows) in the note.

  • Type in Find. Press Enter for the next match and Shift+Enter for the previous match.
  • Type in Replace and click Replace or Replace all.
  • Select Match case, Whole word or Regular expression if necessary.
  • Press Escape to close the bar.

The function searches the open note only. CHA has no search across notes.

Highlights

  1. Select text.
  2. Click Highlight in the toolbar, or right-click and click Highlight.

Do the same again to remove the highlight. Highlights also work in read-only notes.

Comments

  1. Type the comment in the prompt. Do not send it.
  2. Right-click the paragraph that the comment is about.
  3. Click Add comment.

The comment shows as a colored paragraph before that paragraph. To remove it, right-click the comment and click Delete comment.

ANNOTATIONS

When a note in a folder gets a highlight or a comment, CHA makes the item ANNOTATIONS in that folder. It lists the highlights and comments of the notes that are directly in the folder, by note and by chapter.

Click the button at an entry to open the note at that highlight or comment.

Import a text file

Use one of these methods:

  • Open a note and click Content → Upload.
  • Send the full path of the file in the notes prompt.
  • Type the full path in the field of the New note dialog.

The file replaces the content of the note, and the note becomes read-only. If the note still has the name New note, CHA uses the first heading of a Markdown file as the name.

The file must be UTF-8 text of a maximum of 256 KiB. CHA reads Markdown files (for example .md) as Markdown and all other files as plain text. In plain text, two or more empty lines become one paragraph break.

Import a web page

Setup: Page reading must be configured.

Use one of these methods:

  • Send the web address in the notes prompt.
  • Type the web address in the field of the New note dialog.

CHA adds the page at the end of the note. For a YouTube address, CHA imports the transcript of the video. If the note was empty, CHA gives it the title of the page and makes it read-only.

A status line shows the progress. The import continues if you open a different note.

Import a book

  1. Open the menu of a folder and click Import EPUB….
  2. Select the .epub file.

CHA makes a folder with the title of the book. The folder has one read-only note for each chapter, with a number at the start of the name.

Export and import a folder

  • Export folder… saves a folder with all its notes as one file.
  • Import folder… adds such a file below the folder that you select.

Compress a note

Setup: A compression provider must be selected.

A compressed version is a shorter text of the note that a model makes. A chat uses it in place of the full text when you add the note to the chat. Thus a long note uses less of the model's capacity.

  1. Open the menu of a note and click Compress.
  2. Wait. The work continues in the background. The result shows in Events.

When the work is complete, a dot shows on the note in the tree. To read the compressed text, click Show compressed in the menu. To stop a compression that is in work, click Cancel compression.

Compress on a folder compresses all notes in the folder and its subfolders. It ignores summary notes, notes that already have a compressed version, and notes with less than 4 KiB of text.

Important points:

  • A note must have a minimum of 4 KiB of text.
  • When you change a note, the compressed version does not change. Chats continue to use the old compressed text. Click Compress again to make a new version.

Audio for a note

Setup: The note audio service must be configured.

Audio is available only for read-only notes.

To generate the audio:

  1. Open the menu of a read-only note and click Generate audio.
  2. Select a voice and click Generate.
  3. Wait. The work continues in the background. The result shows in Events.

Generate audio on a folder generates audio for the read-only notes directly in that folder that have no audio.

To listen:

  1. Open the note.
  2. Right-click a paragraph and click Play from here.

CHA plays to the end of the note and marks the paragraph that it reads. Press Space to pause and continue. To stop, right-click and click Stop playing. To change the speed, use Playback speed in the toolbar.

CHA does not read code blocks, pictures and comments aloud.

Session summaries

Setup: A compression provider must be selected.

  1. On the Chat tab, open the menu of a session in Recent Sessions.
  2. Click Save summary.

CHA writes a read-only note into the folder Forums / forum name. The note has a short summary and a long summary. The chat shows a message with the name of the note.

When you save the summary of the same session again, CHA replaces the content of that note.

The characters of the forum can read these summaries. See What characters can use.

You cannot save a summary of the Welcome session.

12. Library

In this chapter
  • Upload a folder to a store
  • How the characters use the Library

A Library lets the characters of a forum search large collections of notes. The notes are copied to a cloud store at a provider (OpenAI or Gemini).

Setup: A cloud store API key is necessary. An administrator selects the stores of each forum and manages the stores.

Upload a folder to a store

  1. On the Notes tab, open the menu of a folder.
  2. Click Upload to store.
  3. Select the API key.
  4. If you want, type a description. A good description helps the characters to decide when to search the store.
  5. Click Upload.

The dialog shows the progress. When the upload is complete, the dialog closes, and Events has an entry with the number of uploaded notes.

The result is a new store with the name of the folder. It contains one document for each note in the folder and its subfolders.

To stop an upload, click Cancel. CHA removes the data that it already uploaded.

Important points:

  • The store is a copy. Later changes in the notes do not go to the store.
  • You cannot add notes to an existing store. To update a store, an administrator must delete it. Then upload the folder again.
  • Two stores cannot have the same name.
  • Empty notes and ANNOTATIONS are not uploaded.
  • While an upload runs, you cannot use the other commands of that folder.

How the characters use the Library

Ask your question in a session of a forum that has a Library. The character decides when to search. CHA tells the characters to search the Library before they search the web.

The chat does not show that a Library search occurred, and it does not show a list of sources. A source shows only if the character writes it in the answer.

ChaWeb is the browser client of CHA. It is made for a phone, and it also works in a desktop browser.

Setup: An administrator installs ChaWeb and gives you its address. ChaWeb uses one vault. Forums, characters and voices come from that vault.

Screens

A bar at the bottom has two links:

  • Chats shows the list of sessions, or goes back to the conversation that you used last.
  • Notes shows the notes.

The conversation screen and the note screen have no back button. Use the back function of the browser, or the bottom bar.

Sessions

The session list shows the sessions of one forum, with the newest change first.

  • To see a different forum, tap the forum name at the top and select a forum. The list shows the names of the forum members.
  • To open a session, tap it.
  • To start a session, tap New Session, type a message and send it. ChaWeb creates the session when you send the first message.
  • To delete a session on a phone, swipe the row to the left and tap Delete. With a mouse, point at the row, click the trash icon, and click Delete. ChaWeb does not ask for confirmation.

ChaWeb shows the built-in forum with the name Welcome and its session with the name Entrance.

Send a message

  1. Type in the message field.
  2. Press Enter. On a phone, use the send key of the keyboard.

Ctrl+Enter starts a new line. To get more space for a long message, tap Expand editor.

The addressing rules are the same as in the desktop application: @Name and /mcast work. See Commands and addressing. ChaWeb has no list to select the target.

A note Ref ID that you copied in the desktop application also works here. Send it as the only text of a message to add the note to the chat.

To stop an answer, tap Stop.

To copy a message, tap the copy button below it.

Voice mode

Setup: Voice input and voice output must be configured. The microphone works only when ChaWeb is opened with a secure (HTTPS) address.

Tap Voice mode to start dictation and automatic audio together.

  • When Speak now shows, speak. Your words go into the message field. You cannot type while voice mode is on.
  • To send, tap Send or say the send phrase (default: “over to you”).
  • The answer plays automatically. During that time the status shows Microphone paused. Then the microphone starts again.

The spoken punctuation words are the same as in the desktop application.

Voice mode goes off when you tap the button again, open a different conversation, or put the browser in the background.

Listen to one answer

Tap the Read aloud button below an answer. Tap again to stop. The next tap continues from that position.

Notes

Tap Notes, select a folder at the top, and tap a note.

In ChaWeb you can only read notes. You cannot change them.

If the connection stops

ChaWeb shows Reconnecting and tries again by itself. If that fails, an error message and a Retry button show.

If ChaWeb shows Send status unknown. Check the conversation before sending again., look at the conversation first. Send the message again only if it is not there.

What ChaWeb does not have

  • Rename and download of sessions, session summaries.
  • Delete and cover for single answers.
  • The target list, and the Model and Effort lists.
  • Text files as chat material.
  • Creation and change of notes.
  • Pictures.
  • Settings and the selection of a vault.

14. Commands and addressing

Type these at the start of a chat message.

Input Result
text Goes to the current target.
@Name text Goes to one character, for this message only.
@- text Saves a self-note. No character answers.
@@text Sends @text to the current target.
/mcast text Goes to all characters of the forum.
/mcast @A, @B text Goes to the listed characters.
/clear Deletes all messages of the session, with no confirmation.
##xxxxxx (a Ref ID, as the only text) Adds that note to the chat.
A full file path (as the only text) Adds that text file to the chat.

Rules for @Name:

  • The name ends at the first space. A punctuation mark directly after the name is ignored: @Anna, hello works.
  • CHA looks for the name in this order: the full name; one full word of the name; the start of the name or of one of its words.
  • Capital letters are not important.
  • Nicknames work only with automatic recipient detection, not with @.

The command /detach also exists. It removes a folder record from a chat. The screens give Ref IDs for notes only, so this command has no use in daily work.
